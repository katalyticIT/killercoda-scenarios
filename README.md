
# killercode scenarios

Try them online (click link):

* [ktailor-demo](https://killercoda.com/ktailor-demo/scenario/ktailor-demo) : shows how ktailor changes deployments on the fly, without having to modify the image or the manifest/helm chart.
* [liblogtap-demo](https://killercoda.com/ktailor-demo/scenario/liblogtap-demo) : demonstrates how to redirect a fixed file log of a legacy app to the outside world.
* [martymcfly-demo](https://killercoda.com/ktailor-demo/scenario/martymcfly-demo) : lets containers travel through time easily.
