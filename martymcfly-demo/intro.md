# Welcome to 1985

Let's start the engine and move the container back to the future:
This interactive scenario demonstrates how you can containers make
believe it's a different date and time, using
* libfaketime to manipulate the time and
* kTailor to inject the libfaketime library via an init-container.

Hang on while we're setting up the kubernetes environment for you:
- Installing `cert-manager`.
- Creating the `ktailor` webhook.
- Deploying the [Marty McFly](https://github.com/katalyticIT/Marty-McFly/tree/main) demo applications.

Please wait for the "Cluster is ready!" message in the terminal, then click **Start**.
